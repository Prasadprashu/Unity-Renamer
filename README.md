# Unity Renamer - Prashu

A Unity Editor tool that simplifies bulk renaming of GameObjects, Assets, and project elements directly inside the Unity Editor.

## Features

* Bulk rename multiple objects at once
* Add prefixes and suffixes
* Find and replace text in names
* Automatic numbering support
* User-friendly Unity Editor interface
* Reduces manual work and naming errors

## Why I Built This
Managing large Unity projects often involves renaming hundreds of objects manually. This tool automates repetitive naming tasks, improves consistency, and saves development time.

## Benefits

* Faster project organization
* Consistent naming conventions
* Improved workflow efficiency
* Reduced human error

## Installation

1. Clone the repository.
2. Copy the script into an `Editor` folder inside your Unity project.
3. Open Unity.
4. Access the tool from the Unity menu.
